## Задача №5 "Функции и пространства имён"

Для каждого варианта создайте CMake-проект с двумя cpp-файлами: main.cpp и functions.cpp, а также заголовочным файлом functions.hpp. Объявление функции поместите в functions.hpp внутри указанного в варианте пространства имён, а определение — в functions.cpp внутри того же пространства имён. В main.cpp считайте данные с клавиатуры, вызовите функцию через имя пространства имён (например, digitUtils::sumOfDigits(number)) и выведите результат.

Вариант 1

В пространстве имён digitUtils напишите функцию int sumOfDigits(int number), которая возвращает сумму цифр натурального числа number (number > 0). В main.cpp введите одно натуральное число, вызовите функцию и выведите полученную сумму.
<br><br>

Вариант 2

В пространстве имён mathUtils напишите функцию long long factorial(int number), которая возвращает факториал числа number (0 <= number <= 20), посчитанный циклом. В main.cpp введите число number, вызовите функцию и выведите факториал.
<br><br>

Вариант 3

В пространстве имён sortUtils напишите функцию void sortByExchanges(int values[N], int size), которая сортирует массив целых чисел по неубыванию методом обменов: сравнивайте соседние элементы и меняйте их местами, если они идут в неправильном порядке. В main.cpp введите количество элементов size (size <= 100) и сами элементы, вызовите функцию и выведите отсортированный массив.
<br><br>

Вариант 4

В пространстве имён checkUtils напишите функцию bool isPrime(int number), которая возвращает true, если натуральное число number (number > 1) простое, и false иначе. В main.cpp введите число, вызовите функцию и выведите сообщение "простое" или "составное".
<br><br>

Вариант 5

В пространстве имён checkUtils напишите функцию bool isPalindrome(int number), которая возвращает true, если натуральное число number одинаково читается слева направо и справа налево (например, 1221). В main.cpp введите число, вызовите функцию и выведите результат проверки.
<br><br>

Вариант 6

В пространстве имён numberUtils напишите функцию int reverseNumber(int number), которая возвращает число, записанное цифрами натурального числа number в обратном порядке (например, 1234 -> 4321, 1200 -> 21). В main.cpp введите число, вызовите функцию и выведите перевёрнутое число.
<br><br>

Вариант 7

В пространстве имён digitUtils напишите функцию int countEvenDigits(int number), которая возвращает количество чётных цифр (включая цифру 0) в натуральном числе number. В main.cpp введите число, вызовите функцию и выведите найденное количество.
<br><br>

Вариант 8

В пространстве имён mathUtils напишите функцию int maxOfThree(int first, int second, int third), которая возвращает наибольшее из трёх целых чисел. В main.cpp введите три числа, вызовите функцию и выведите максимум.
<br><br>

Вариант 9

В пространстве имён mathUtils напишите функцию int power(int base, int exponent), которая возвращает base в степени exponent (exponent >= 0), посчитанную циклом без использования стандартной функции возведения в степень. В main.cpp введите основание и показатель степени, вызовите функцию и выведите результат.
<br><br>

Вариант 10

В пространстве имён digitUtils напишите функцию double averageOfDigits(int number), которая возвращает среднее арифметическое цифр натурального числа number (number > 0). В main.cpp введите число, вызовите функцию и выведите результат с двумя знаками после десятичной точки.
<br><br>
