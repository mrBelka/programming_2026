# what_is_this_file.md

Описание назначения служебных файлов проекта.

## Файлы pre-commit tools

- `.pre-commit-config.yaml` — конфигурация фреймворка [pre-commit](https://pre-commit.com/). Список хуков, которые запускаются перед коммитом: удаление лишних пробелов в конце строк, добавление перевода строки в конец файла, проверка YAML, форматирование C++ и CMake.
- `.clang-format` — настройки автоформатирования C++ кода (отступ 2 пробела, скобки циклов и условий на той же строке, скобки функций с переносом). Используется хуком `clang-format`.
- `.cmake-format.yaml` — настройки форматирования и проверки CMake-файлов. Используется хуками `cmake-format` и `cmake-lint`.

## AGENTS.md

Инструкции для ИИ-агентов, работающих с репозиторием: стиль кода, стиль коммитов и обязательные действия перед коммитом (запуск pre-commit).

## CHANGELOG.md

Журнал изменений проекта в формате [Keep a Changelog](https://keepachangelog.com/). Фиксирует добавленные, изменённые и удалённые возможности по разделам и датам.

## .gitignore

Список файлов и директорий, которые Git не должен отслеживать. Например, каталог `build` с результатами сборки.
